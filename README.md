# ❤️ Predicting Heart Disease with K-Nearest Neighbors

## Overview

This project predicts the presence of heart disease using machine learning techniques on the Cleveland Heart Disease dataset from the UCI Machine Learning Repository.

Multiple supervised learning algorithms were developed and compared, including:

- K-Nearest Neighbors (KNN)
- Logistic Regression
- Random Forest

The objective is to evaluate different classification models and identify the most suitable algorithm for heart disease prediction.

---

## Dataset

Source:

UCI Machine Learning Repository

Dataset:

Cleveland Heart Disease Dataset

Number of samples:

303

Features:

13 clinical attributes

Target:

Presence or absence of heart disease
