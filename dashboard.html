🩺 The Clinical Rationale: Minimizing Medical Risk

In diagnostics applications of artificial intelligence, model optimization metrics must represent clinical safety. If a machine learning algorithm misclassifies a healthy patient as diseased (False Positive), the doctor will run secondary checks. The patient faces slight anxiety, but they are medically safe.

🚨 However, if the algorithm misclassifies a patient with severe blockages as healthy (False Negative), the patient is sent home, potentially leading to fatal coronary outcomes.

Therefore, the primary optimization metric for this project is **Recall (Sensitivity)**. Our goal was to train a classifier that achieves **zero False Negatives** while maintaining high overall precision.

⚙️ Machine Learning Pipeline

The pipeline consists of clean, isolated phases starting from raw text ingestion:

1. Imputation: Missing clinical values in fluoroscopy major vessels (`ca`) and thalassemia types (`thal`) were imputed using robust median values.
2. Binarization: The multi-class target variable (scores 0 to 4) was mapped to binary labels: `0` (Healthy) vs `1` (Heart Disease Present).
3. Standard Scaling: Numerical variables such as age, blood pressure, and cholesterol were standard-scaled. This step is critical for distance-based algorithms like KNN to prevent scaling imbalances from skewing distances.
4. Hyperparameter Tuning: KNN was trained iteratively across $K=1$ to $K=31$, identifying **$K=9$** as the optimal neighbor count.

🏆 Champion Model: Tuned KNN (K=9)

Through systematic comparison, the Tuned K-Nearest Neighbors ($K=9$) model was selected as our preferred model:

📈 **Accuracy (90.16%):** Outperforms the Logistic Regression baseline (86.89%) and Random Forest (88.52%).
🏥 **Recall (100.00%):** Outperforms Logistic Regression (92.86%) and Random Forest (96.43%), ensuring zero False Negatives.
💎 **F1-Score (90.32%):** Achieves the best overall balance between false positives and false negatives.
